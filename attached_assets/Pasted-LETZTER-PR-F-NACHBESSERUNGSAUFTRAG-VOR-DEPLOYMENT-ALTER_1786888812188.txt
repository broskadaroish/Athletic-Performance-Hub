==================================================
1. TRAININGSPLAN-UI BEGRIFFLICH SAUBER TRENNEN
==================================================

Aktuell kann ein Spieler z.B. sein:

Alter: 9 Jahre
Fußballklasse: U11
Testreferenz: U10
interne Plangruppe: U8

Das ist technisch möglich, aber die UI darf die interne Plangruppe nicht
einfach als „Altersgruppe U8“ bezeichnen.

Bitte alle Stellen prüfen, an denen _alter_zu_plangruppe() angezeigt wird.

Statt:

„Altersgruppe: U8“

besser:

„Trainingsstufe: U8/U9“
oder
„Trainingsgruppe: 8–9 Jahre“

WICHTIG:
Fußballklasse bleibt separat:
„Fußballklasse: U11“

Testreferenz separat:
„Testreferenz: U10 (Alter 9–10)“

Interne Belastungs-/Plangruppe separat:
„Trainingsstufe: U8/U9“

Keine Logikänderung nötig, nur klare Bezeichnung.

8. DEFIZIT-KONSISTENZTEST
==================================================

Für jeden Test:

Wenn UI sagt:
„Normbereich“ / „Unauffällig“
→ Trainingsplan darf daraus KEIN Defizit erzeugen.

Wenn UI sagt:
„Verbesserungsbedarf“ / relevante Auffälligkeit
→ Defizit muss im Trainingsplan ankommen.

Wenn keine gültige Referenz existiert:
→ Messwert anzeigen
→ kein künstliches Defizit.
