PRÜFUNG – WARUM WIRD BEI „PASSWORT VERGESSEN“ KEINE E-MAIL VERSENDET?

WICHTIG:
NOCH NICHTS ÄNDERN.

Zuerst ausschließlich analysieren und mir einen Diagnosebericht geben.

Aktuelles Problem:

Wenn ein Benutzer auf:

„Passwort vergessen?“

klickt und seine hinterlegte E-Mail-Adresse bzw. seinen Benutzernamen eingibt, wird keine E-Mail zugestellt.

SMTP_PASSWORD wurde von mir bereits als Replit Secret hinterlegt.

Prüfe jetzt systematisch, warum keine E-Mail versendet wird.

==================================================

1. REPLIT SECRETS / ENVIRONMENT VARIABLES PRÜFEN
   ==================================================

Prüfe, ob folgende Environment Variables im laufenden Prozess tatsächlich verfügbar sind:

* SMTP_HOST
* SMTP_PORT
* SMTP_USERNAME
* SMTP_PASSWORD
* SMTP_FROM
* SUPPORT_EMAIL
* APP_BASE_URL

WICHTIG:

NIEMALS den Wert von SMTP_PASSWORD ausgeben.

Nur melden:

SMTP_PASSWORD vorhanden: JA / NEIN

Zusätzlich prüfen:

* Ist der Secret-Name exakt „SMTP_PASSWORD“ geschrieben?
* Enthält der Name versehentlich Leerzeichen?
* Wird SMTP_PASSWORD im Python-Prozess tatsächlich über os.environ / os.getenv geladen?
* Läuft eventuell noch ein alter Prozess, der den neu gesetzten Secret nicht geladen hat?

==================================================
2. SMTP-KONFIGURATION PRÜFEN
============================

Prüfe die aktuell verwendeten Werte, aber ohne Passwort anzuzeigen.

Erwartet:

SMTP_HOST = smtp.ionos.de
SMTP_PORT = 465
SMTP_USERNAME = [noreply@aphsystem.de](mailto:noreply@aphsystem.de)
SMTP_FROM = [noreply@aphsystem.de](mailto:noreply@aphsystem.de)
SUPPORT_EMAIL = [support@aphsystem.de](mailto:support@aphsystem.de)

Prüfe:

* Wird Port 465 verwendet?
* Wird SMTP_SSL verwendet?
* Wird tatsächlich smtp.ionos.de angesprochen?
* Wird SMTP_USERNAME korrekt geladen?
* Wird SMTP_PASSWORD an SMTP.login() übergeben?
* Wird SMTP_FROM korrekt verwendet?

==================================================
3. SMTP-LOGIN DIREKT TESTEN
===========================

Führe einen isolierten SMTP-Verbindungstest durch.

Ablauf technisch:

1. Verbindung zu smtp.ionos.de:465 herstellen
2. SSL-Verbindung aufbauen
3. Login mit SMTP_USERNAME und SMTP_PASSWORD versuchen
4. Verbindung sauber schließen

Keine E-Mail versenden, wenn für diese Diagnose nicht notwendig.

Berichte nur:

* Verbindung zum SMTP-Server möglich: JA / NEIN
* SMTP-Authentifizierung erfolgreich: JA / NEIN

Falls Fehler:
nur Fehlertyp und sichere Fehlermeldung anzeigen.

NIEMALS:

* Passwort ausgeben
* Passwort teilweise ausgeben
* Secret dumpen
* Environment komplett anzeigen

==================================================
4. PASSWORT-RESET-FLOW PRÜFEN
=============================

Prüfe den tatsächlichen Codepfad von:

„Passwort vergessen?“

bis zum E-Mail-Versand.

Prüfe der Reihe nach:

1. Wird die eingegebene E-Mail / Benutzername korrekt verarbeitet?
2. Wird normalize_email() verwendet?
3. Wird der Benutzer in der Datenbank gefunden?
4. Ist der Benutzer aktiv?
5. Ist die E-Mail-Adresse bestätigt?
6. Wird pw_reset_token_erzeugen() tatsächlich aufgerufen?
7. Wird ein Reset-Token erzeugt?
8. Wird der Token in der Datenbank gespeichert?
9. Wird eine Ablaufzeit gesetzt?
10. Wird send_password_reset() tatsächlich aufgerufen?
11. Gibt send_password_reset() Erfolg oder Fehler zurück?
12. Wird ein SMTP-Fehler eventuell abgefangen und anschließend ignoriert?
