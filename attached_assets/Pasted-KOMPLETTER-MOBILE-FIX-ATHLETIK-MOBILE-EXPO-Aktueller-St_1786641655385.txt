==================================================
1. ANDROID / EXPO GO FEHLER
==================================================

Prüfe:

- Expo SDK-Version
- expo-notifications-Version
- usePushNotifications.ts
- alle imports von expo-notifications

Expo Go unterstützt Android Remote Push Notifications ab SDK 53 nicht mehr.

Deshalb:

Im Expo-Go-Testbetrieb Push-Registrierung sauber überspringen/deaktivieren.

Die App darf NICHT abstürzen.

WICHTIG:

Push-Architektur erhalten, damit Push später in einem echten:

- Development Build
- Android Production Build
- iOS Build

weiterhin möglich ist.

Keine Push-Funktion vortäuschen.

==================================================
2. MOBILE LOGIN HTTP 500
==================================================

Finde exakt den Login-Endpunkt, den Athletik Mobile verwendet.

Prüfe die konkrete serverseitige Exception hinter:

„Datenbankfehler beim Login“

Nicht nur die allgemeine 500-Meldung betrachten.

Serverseitig technische Exception loggen,
aber niemals Passwort, Token oder Secret.
