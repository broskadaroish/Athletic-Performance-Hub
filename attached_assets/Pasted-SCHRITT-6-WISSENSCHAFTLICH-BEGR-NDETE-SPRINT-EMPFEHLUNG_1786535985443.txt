1. WISSENSCHAFTLICHE GRUNDLAGE
   ==================================================

Eine Studie mit 66 College-Footballspielern untersuchte Zusammenhänge zwischen Muskelvolumen der unteren Extremität und maximaler Sprintgeschwindigkeit.

Ergebnisse:

Psoas major:
R² = 0,499

Gluteus medius:
R² = 0,451

Gluteus maximus:
R² = 0,365

Pectineus:
R² = 0,323

Rectus femoris:
R² = 0,321

Piriformis:
R² = 0,303

Adductor magnus:
R² = 0,287

Gluteus minimus:
R² = 0,280

Semitendinosus:
R² = 0,269

Semimembranosus:
R² = 0,266

Die Kombination:

Psoas major
+
Gluteus medius
+
Piriformis

erklärte ungefähr 57–59 % der Varianz der maximalen Sprintgeschwindigkeit.

==================================================
2. WICHTIGE INTERPRETATIONSREGEL
================================

Diese Studie zeigt Zusammenhänge.

Sie beweist NICHT:

* dass ein großer Psoas automatisch schneller macht
* dass ein langsamer Spieler automatisch einen schwachen Psoas besitzt
* dass Muskelgröße allein Sprintleistung bestimmt
* dass aus einer Sprintzeit ein bestimmtes Muskeldefizit diagnostiziert werden kann

Daher darf das System NIEMALS allein aufgrund einer schlechten Sprintzeit anzeigen:

"Psoas schwach"

oder:

"Gluteus medius Defizit"

oder vergleichbare kausale Aussagen.

Stattdessen nur Formulierungen wie:

* möglicher Trainingsschwerpunkt
* leistungsrelevanter Bereich
* Trainingsfeld
* funktioneller Schwerpunkt
* auffälliger Leistungsbereich

===========================

A) Beschleunigung 0–10 m

B) Beschleunigung 10–20 m

C) Übergang 20–30 m

D) maximale Sprintgeschwindigkeit

F) Links-/Rechts-Asymmetrie aus anderen geeigneten vorhandenen Tests

WICHTIG:

15. VERKNÜPFUNG MIT FMS

==================================================
16. VERKNÜPFUNG MIT Y-BALANCE
=============================

Bestehende Y-Balance-Daten berücksichtigen.

Wenn:

Sprintauffälligkeit
+
relevante Y-Balance-Asymmetrie

dann:

* Seitenunterschied berücksichtigen
* einbeinige Kontrolle/Stabilität priorisieren
* Training nicht ausschließlich auf maximale Sprintbelastung fokussieren

Keine medizinische Aussage daraus ableiten.

* Sprinttechnik
* Sprintbelastung

* Reaktivkraft
* Maximalkraft

============================

Sprintauffälligkeit
+

"Gluteus medius schwach"

38. TESTFÄLLE
=============

TEST A:
Spieler ohne Sprinttest.

Erwartung:

* kein Sprintdefizit
* keine Muskelbehauptung
* NO_DATA

TEST B:
Sprinttest vorhanden, FMS/Y-Balance unauffällig.

Erwartung:

* Sprinttraining / Explosivität stärker berücksichtigen
* keine erfundene Stabilitätsstörung

TEST C:
Sprintauffälligkeit + Hüftstabilitätsauffälligkeit.

Erwartung:

* Hüft-/Beckenstabilität höher priorisiert
* keine Aussage "Gluteus medius schwach"

TEST D:
Sprintauffälligkeit + Rumpfstabilitätsauffälligkeit.

Erwartung:

* Core ergänzen
* Sprint bleibt Bestandteil

TEST E:
Sprintauffälligkeit + Y-Balance-Asymmetrie.

Erwartung:

* Seitenunterschied / Stabilität berücksichtigen

TEST F:
Gute Sprintwerte.

Erwartung:

* kein künstliches Sprintdefizit
* Erhaltungs-/Leistungsentwicklung möglich

TEST G:
Bestehender Plan vor Schritt 6.

Erwartung:

* Plan bleibt unverändert

TEST H:
Neuer Plan mit Sprintdefizit.

Erwartung:

* Sprint-/Explosivübungen stehen vor ermüdender Kraft

TEST I:
30-Minuten-Plan.

Erwartung:

* Trainingszeit wird eingehalten

TEST J:
Keine Diagnosedaten.

Erwartung:

* Basis-Modus aus Schritt 3
* keine neuen Sprintdefizite
