==================================================
TEIL A – STREAMLIT nav_section FEHLER BEHEBEN
==================================================

1. URSACHE

Der Fehler entsteht, weil der Wert:

st.session_state["nav_section"]

nach Instanziierung eines Streamlit-Widgets mit:

key="nav_section"

direkt verändert wird.

Das ist in Streamlit nicht erlaubt.

Suche ALLE Stellen wie:

st.session_state["nav_section"] = ...

oder:

st.session_state.nav_section = ...

die ausgeführt werden können, nachdem das Widget mit key="nav_section" bereits erstellt wurde.

==================================================
2. KEIN DIREKTES SCHREIBEN NACH WIDGET-ERSTELLUNG

Folgende Struktur ist NICHT erlaubt:

nav = st.radio(..., key="nav_section")

...

st.session_state["nav_section"] = "Info"

Das entfernen.

==================================================
3. ZENTRALE NAVIGATION VERWENDEN

Erstelle bzw. verwende eine zentrale Navigationsfunktion.

Beispielprinzip:

def navigate_to(target):
    st.session_state["_nav_target"] = target
    st.rerun()

Dann GANZ VOR der Erstellung des nav_section-Widgets:

if "_nav_target" in st.session_state:
    st.session_state["nav_section"] = st.session_state.pop("_nav_target")

Erst DANACH:

st.radio(...)
oder
st.segmented_control(...)
mit key="nav_section"

erzeugen.

==================================================
4. ALTERNATIV CALLBACK

Falls die bestehende Architektur besser mit on_change/on_click funktioniert:
saubere Streamlit-Callbacks verwenden.

Aber weiterhin:

NICHT nach Widget-Erstellung direkt in dessen Session-State-Key schreiben.
