2. WEBHOOK-FEHLERBEHANDLUNG

Wenn ein gültig signiertes Stripe-Event empfangen wurde,
aber die interne Verarbeitung / DB-Aktualisierung fehlschlägt:

→ NICHT HTTP 200 zurückgeben
→ HTTP 500 zurückgeben

Nur wenn die Event-Verarbeitung wirklich erfolgreich abgeschlossen wurde:
→ HTTP 200

WICHTIG FÜR IDEMPOTENZ:
Ein Stripe-Event darf erst als erfolgreich verarbeitet markiert werden,
wenn seine komplette Verarbeitung erfolgreich beendet wurde.

Falls ein Event wegen DB-/Programmfehler scheitert,
muss ein späterer erneuter Zustellversuch verarbeitet werden können.
