PHASE 0E – Programmbranding, Windows-Installation, Setup.exe, Urheberrecht und Veröffentlichung
Projektziel
Du arbeitest an der bestehenden Software Bruce Football Performance Diagnostics.
Diese Teilphase dient der professionellen Vorbereitung der Software für die Veröffentlichung als Windows-Anwendung.
Es sollen keine neuen Diagnostikmodule entwickelt werden.
Der Schwerpunkt liegt auf:
•	professionellem Erscheinungsbild 
•	Windows-Installation 
•	Setup.exe 
•	Branding 
•	Copyright 
•	Kontaktinformationen 
•	Veröffentlichungsvorbereitung 
Die Plattform muss nach Abschluss dieser Phase vollständig lauffähig sein.

Langfristiges Projektziel
Die Plattform soll später sowohl als
•	Windows-Software (.exe) 
•	Web-Anwendung 
•	Cloud-Plattform 
betrieben werden können.
Der Benutzer soll die Software wie jede normale Windows-Software installieren können.

Aufgabe 8 – Windows-Installation
Nach erfolgreichem Abschluss von Phase 0 soll zusätzlich eine installierbare Windows-Version erstellt werden.
Erstelle ein professionelles Windows-Installationsprogramm (Setup.exe) für Bruce Football Performance Diagnostics.
Die Installation soll:
•	einen Installationsassistenten besitzen, 
•	das Programm in den Standard-Programmordner installieren, 
•	eine Desktop-Verknüpfung erstellen, 
•	einen Eintrag im Windows-Startmenü erstellen, 
•	das von mir bereitgestellte Programm-Icon verwenden, 
•	den Programmnamen Bruce Football Performance Diagnostics anzeigen, 
•	vollständig offline funktionieren, 
•	alle benötigten Dateien automatisch mitinstallieren, 
•	die lokale Datenbank korrekt einrichten, 
•	alle erforderlichen Bibliotheken und Abhängigkeiten automatisch installieren. 
Der Benutzer soll keine zusätzliche Software (z. B. Python) installieren müssen.
Verwende hierfür geeignete Werkzeuge, beispielsweise:
•	PyInstaller (für die ausführbare Datei) 
•	Inno Setup oder NSIS (für das Installationsprogramm)
