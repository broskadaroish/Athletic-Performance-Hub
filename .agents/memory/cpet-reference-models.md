---
name: Protocol-specific CPET reference data
description: Scientific constraint for selecting VO₂ reference models across CPET devices and protocols.
---

CPET reference equations must be selected and applied only for the matching device, exercise protocol, outcome definition, and acquisition/averaging method; a single cross-device VO₂ reference model is not defensible.

**Why:** Recent systematic and ERS/GLI work found material heterogeneity from protocol, metabolic-cart type, and peak-value averaging, preventing reliable global VO₂peak reference ranges.

**How to apply:** Keep treadmill/Bruce, ramp-cycle, and field/lactate assessments separate. Do not convert a published threshold or equation to another device or protocol without a source that explicitly validates that transfer.

For the Bruce-specific Griffith comparison, treat the published equation as available only after the stored test proves the complete standard Bruce stage sequence (speed, grade, and 180-second duration), direct VO₂, test-day age/weight/sex, and documented effort quality. A protocol name alone is not evidence.

**Why:** Mutable or free-text protocol metadata can otherwise make a non-Bruce or altered-duration test appear comparable and produce a scientifically invalid reference result.

**How to apply:** When a required datum or the exact standard stage pattern is absent, keep the assessment neutral; never fall back to generic VO₂ or threshold cutoffs and never create a training deficit from it.
